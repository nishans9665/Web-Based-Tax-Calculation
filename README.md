# Web Based Tax & Leasing Calculator

A single-page app implementing the assignment requirements using **HTML, CSS, and JavaScript**.

## Features
- Tabbed navigation
- Withholding Tax (Rent / Bank Interest / Dividend)
- Monthly Payable Tax (progressive slabs)
- Annual Income Tax (progressive slabs)
- SSCL calculation (2.5% sale tax + 15% VAT on after-sale amount)
- Leasing: EMI, 3/4/5-year plan comparison, and reverse calculation
- Inline validation, accessible results, reset/clear actions

## Usage
Open `index.html` in a browser. No build step required.
